# 🔵 USDC Vault Dashboard

This project is a modern stablecoin dashboard interface featuring a glassmorphism design, responsive layout, animations, and blockchain-inspired portfolio monitoring features.

## 💰 About USDC

USDC (USD Coin) is a digital dollar stablecoin designed to maintain a value close to one US dollar.

This dashboard is a visual portfolio interface created to display wallet information, asset balance, blockchain status, and digital asset analytics.

---

## 🔐 Security

This project is a frontend dashboard demonstration.

The login system is a local interface feature and should not be used for real wallet security or authentication.

For real cryptocurrency applications, always use secure wallet providers, audited smart contracts, and proper authentication systems.
